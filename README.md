Full Moon Rampage

An 8-bit top-down werewolf action game. Hordes of villagers with torches and pitchforks come for you; you send them flying. The terrain is procedurally generated from a random seed, and the night lasts as long as you do.

Play it: enable GitHub Pages on this repo (Settings → Pages → deploy from main, root folder) and open the URL it gives you.

Controls
Action	Keyboard	Mouse	Phone
Move and face	WASD / arrow keys	—	drag on the left side
Claw (launches villagers)	J	left button	CLAW
Bite / devour	K	right button	BITE
Dash	Space / Shift	—	DASH
Howl (when the bar is full)	Q	—	HOWL
Pause	P / Esc	—	II
Mute	M	—	♪
New world	N (title or pause screen)	—	—

Devour 3 villagers to heal. Brutes, crossbow hunters and hounds join the hunt as the night wears on, and a horde arrives every so often.
